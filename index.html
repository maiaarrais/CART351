Project I – AQI Terminal Explorer
Interactive web project · CART351

A simple terminal-style interface that retrieves and displays live Air Quality Index data for Montreal locations. The project focuses on parsing structured data, presenting it clearly, and offering a minimal but functional command-line experience.

Project II – Find Your Balance (Booking Website)
Web design · scheduling interface

A calm, minimalist class-booking experience inspired by wellness studio interfaces. Users can browse available sessions, explore image-based class cards, filter by day, and reserve a spot. The project explores clean UI structure, layout hierarchy, and accessible interaction patterns.

Project III – Rising Intentions: A Collective Neon Skyline
Shared states · networked experiment

A collaborative online “skyline” where every user contributes their own window. Each window represents an individual’s unique response or perspective, forming a collective architecture. The project explores how separate personal inputs can build a shared digital environment.
